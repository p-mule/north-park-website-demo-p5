# North Park School website

A four-page site for North Park School, Lusaka: Home, About us, Admissions, Gallery (Class of 2026) and How to apply.

All files sit together in one folder:

- `index.html` is the page and the file GitHub Pages looks for.
- `styles.css` holds the colours, fonts and layout.
- `script.js` switches between the pages and builds the application email.
- The `.jpg` files are the logo and photos. They must stay in the same place as `index.html`.

## Publish with GitHub Pages

1. Upload every file in this folder to the main branch of a repository.
2. Go to **Settings → Pages**, set **Source** to "Deploy from a branch", choose `main` and `/ (root)`, then save.
3. After a minute or two, the live link appears at the top of the Pages settings.
